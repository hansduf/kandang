PENJELASAN DIAGRAM LENGKAP:
===========================

1. ACTORS (2 Aktor Sistem):
   
   👤 PEKERJA KANDANG (Hijau)
   - Akses terbatas, hanya fitur input & view
   - Login → Akses menu sesuai role
   - Tidak bisa manage data master
   
   👨‍💼 PEMILIK PETERNAKAN (Kuning)
   - Akses penuh ke semua fitur operasional
   - Full CRUD untuk kandang, harga, penjualan
   - Akses laporan & analisis

2. AUTHENTICATION BASE USE CASES:
   
   ✓ Login
     - Semua actor harus login dulu
     - Validasi kredensial
     - Set role & session
   
   ✓ Logout
     - Semua actor bisa logout
     - Clear session

3. SHARED USE CASES (Accessible by multiple actors):
   
   ✓ Lihat Dashboard (Pekerja + Pemilik + Admin)
     • Pekerja: Ringkasan produksi kandang mereka
     • Pemilik: Ringkasan lengkap bisnis
     • Admin: View monitoring
   
   ✓ Lihat Stok Telur (Pekerja + Pemilik)
     • Info real-time stok (butir & kg)
     • Alert jika menipis/habis
   
   ✓ Lihat Riwayat Produksi (Pekerja + Pemilik)
     • Pekerja: Histori kandang mereka saja
     • Pemilik: Histori semua kandang (bisa filter, edit, delete)

3. PEKERJA-SPECIFIC USE CASES:
   
   ✓ Input Produksi Telur Harian (Pekerja only)
     → include: Konversi Satuan Otomatis
     • Input tanggal, satuan (butir/kg), jumlah
     • Auto-konversi ke satuan lain
     • Auto-increment stok
     • Only kandang sendiri

4. PEMILIK-SPECIFIC USE CASES:

   A. KELOLA DATA KANDANG
      ├─ include: Tambah Kandang
      ├─ include: Edit Kandang
      └─ include: Hapus Kandang (cascade)

   B. KELOLA MASTER HARGA TELUR
      ├─ include: Tambah Harga (never delete, historis)
      └─ include: Lihat Riwayat Harga

   C. INPUT PENJUALAN TELUR
      ├─ include: Konversi Satuan Otomatis
      ├─ include: Validasi Stok
      └─ include: Lihat Stok Telur (validate available)
      • Multiple items per transaksi
      • Auto-decrement stok
      • Transaction-based (atomicity)

   D. LIHAT LAPORAN PRODUKSI
      ├─ include: Tampilkan Grafik Produksi (garis + donut)
      ├─ extend: Export PDF
      └─ extend: Export Excel
      • Query dengan filter bulan/tahun/kandang
      • Tabel detail + visualisasi

   E. LIHAT LAPORAN PENJUALAN
      ├─ include: Tampilkan Grafik Penjualan (bar chart)
      ├─ include: Lihat Detail Penjualan (modal)
      ├─ extend: Export PDF
      └─ extend: Export Excel
      • Summary cards (total trx, harga, rata-rata)
      • Tabel penjualan dengan expand detail

6. ADMIN-SPECIFIC USE CASES:

   A. KELOLA DATA USER
      ├─ include: Tambah User
      ├─ include: Edit User
      └─ include: Hapus User
      • Create pekerja & pemilik accounts
      • Assign role dan kandang
      • Reset password

   B. ATUR PENGATURAN SISTEM
      └─ include: Atur Konversi Satuan
      • Konfigurasi konversi (butir ↔ kg)
      • Default: 1kg = 16 butir
      • Bisa diubah sesuai kebutuhan

7. INTERNAL/SYSTEM USE CASES (pink - bukan actor call, tapi sub-process):
   
   ✓ Konversi Satuan Otomatis
     - Include dari: Input Produksi, Input Penjualan
     - Ambil dari tabel pengaturan, bukan hardcode
   
   ✓ Validasi Stok
     - Include dari: Input Penjualan
     - Check stok mencukupi sebelum commit
   
   ✓ Tampilkan Grafik
     - Include dari: Laporan Produksi, Laporan Penjualan
     - Render Chart.js (garis, donut, bar)
   
   ✓ Export PDF/Excel
     - Extend dari: Laporan Produksi, Laporan Penjualan
     - Optional, hanya jika user minta export

RELATIONSHIP EXPLAINED:
=======================

include (─────→):
  Dependency wajib yang selalu terjadi
  Contoh: Login include ke semua di dalam sistem
  Contoh: Input Penjualan include Konversi Satuan

extend (- - - →):
  Optional, hanya terjadi dalam kondisi tertentu
  Contoh: Laporan extend Export PDF (hanya jika user klik export)

CARA PAKAI DI DRAW.IO:
====================
1. Buka draw.io
2. Buat diagram baru
3. Di menu, pilih: Arrange → Diagram → Mermaid
4. Paste seluruh kode di atas (mulai dari "graph TB" sampai "style Transaksi")
5. Diagram akan terrender otomatis
6. Save dan export sesuai kebutuhan

ALTERNATIF (Mermaid Live Editor):
==================================
1. Buka: https://mermaid.live
2. Paste kode di text editor
3. Adjust styling sesuai preferensi
4. Export sebagai SVG atau PNG
